# INTERS 가치투자 트래커 (웹앱)

미너비니와 피터 린치의 기준으로 미국 상장 종목(시총 $50M 이상)을 분류하고 점검하는 웹앱입니다. 트렌드 템플릿 트래커와 같은 방식으로 배포하며, 동아리 내부 학습용·개인 용도로만 사용합니다.

## 폴더 구성

| 파일 | 역할 |
| --- | --- |
| `app.py` | 웹 화면 (필터, 결과 표, 종목 상세, 체크리스트) |
| `scanner.py` | 전체 스캔: 종목 목록과 SEC 재무 데이터로 지표 계산 |
| `detail.py` | 종목 상세: 애널리스트·내부자 데이터 (종목을 열 때만 조회) |
| `requirements.txt` | 서버에 설치할 패키지 목록 |
| `.streamlit/config.toml` | 화면 테마 |

## 배포 방법

트렌드 템플릿 트래커와 같습니다. 새 GitHub 저장소에 파일을 올리고, share.streamlit.io에서 `app.py`를 지정해 배포합니다. 이번에는 **Secrets 설정이 한 단계 더** 필요합니다.

**SEC 연락처 등록 (필수)**
재무 데이터를 주는 SEC는 요청마다 연락처를 밝히도록 요구합니다. 등록하지 않으면 요청이 거절될 수 있습니다.

1. 배포 화면의 `Advanced settings`(이미 배포했다면 앱 메뉴의 `Settings` → `Secrets`)를 엽니다.
2. 아래 한 줄을 입력하고 저장합니다. 이메일은 실제로 받을 수 있는 주소로 바꿔 주세요.

```
SEC_USER_AGENT = "INTERS Value Tracker 본인이메일@example.com"
```

Python 버전은 3.12를 권장합니다.

## 사용 방법

1. 왼쪽 사이드바에서 `스캔 시작`을 누릅니다. 5~10분 정도 걸리고, 창을 닫아도 서버에서 계속 진행됩니다.
2. 재무 데이터는 분기마다 바뀌므로 실적 시즌이 끝날 때마다 한 번씩 스캔하면 충분합니다.
3. 린치 분류, 시가총액, 섹터 태그와 네 가지 토글(PEG 1 이하, 자사주 매입 중, 흑자 기업만, 경고 없는 종목만)로 종목을 좁힙니다.
4. 표에서 행을 선택하거나 `종목 바로 보기`에서 티커를 고르면 아래에 상세 화면이 열립니다. 상세 화면은 실적, 애널리스트, 가치평가·재무, 주주환원·수급, 체크리스트 탭으로 나뉩니다.
5. 사이드바의 저성장 기준(기본 5%)을 바꾸면 분류가 바로 다시 계산됩니다.

## 데이터 출처와 한계

- **재무 데이터: SEC XBRL 공시.** 미국 정부 공개 자료라 공유에 문제가 없습니다. 미국 회계기준으로 공시하지 않는 해외 기업(20-F 제출 기업 등)은 재무 지표가 비어 있습니다. 회사마다 공시 항목 이름이 달라 일부 지표가 `-`로 나올 수 있습니다.
- **4분기 실적:** 연간 보고서에만 나오므로 연간 값에서 1~3분기 합을 빼서 계산합니다.
- **종목 목록·시가총액·주가·섹터: Nasdaq 스크리너.** 섹터는 GICS 11개 섹터로 매핑한 값이라 공식 분류와 일부 다를 수 있습니다. Nasdaq 목록이 막히면 SEC 목록과 Yahoo 주가로 대체 스캔합니다.
- **애널리스트·내부자 데이터: Yahoo Finance.** 종목을 열 때만 조회하고 6시간 동안 저장해 둡니다. 개인 용도 전제의 데이터이므로 외부 공개나 게시는 피해 주세요.
- **잭스 랭크:** 약관상 재배포가 금지되어 있어 `잭스에서 보기` 링크로만 제공합니다.
- **무료 데이터로 확인할 수 없는 항목:** 매출 서프라이즈, 가이던스 하향 후 서프라이즈 여부, 특정 고객 의존도, 시장점유율. 체크리스트에 `직접 확인` 항목으로 표시됩니다.

## 내 컴퓨터에서 먼저 확인하기 (선택)

```
pip install -r requirements.txt
set SEC_USER_AGENT=INTERS Value Tracker 본인이메일@example.com   (맥은 export SEC_USER_AGENT="...")
streamlit run app.py
```
