# INTERS 가치투자 트래커 (웹앱)

미너비니와 피터 린치의 기준으로 미국 상장 종목(시총 $50M 이상)을 분류하고 점검하는 웹앱입니다. 동아리 내부 학습용·개인 용도로만 사용합니다.

## 구조

전체 시장 스캔은 메모리를 많이 써서 무료 Streamlit 서버에서는 앱이 꺼질 수 있습니다. 그래서 역할을 나눴습니다.

- **스캔:** GitHub Actions가 매주 토요일 오전 9시에 자동으로 `run_scan.py`를 실행하고, 결과를 `data/scan.json.gz`로 저장소에 올립니다.
- **앱:** Streamlit 앱은 이 결과 파일을 읽어서 보여 주기만 합니다. 저장소에 새 결과가 올라오면 앱이 자동으로 다시 시작되며 새 데이터를 불러옵니다.

## 폴더 구성

| 파일 | 역할 |
| --- | --- |
| `app.py` | 웹 화면 (필터, 결과 표, 종목 상세, 체크리스트) |
| `scanner.py` | 종목 목록과 SEC 재무 데이터로 지표 계산 |
| `run_scan.py` | 스캔을 실행하고 결과 파일 저장 |
| `detail.py` | 종목 상세: 애널리스트·내부자 데이터 (종목을 열 때만 조회) |
| `.github/workflows/scan.yml` | 주간 자동 스캔 설정 |
| `requirements.txt` | 앱 서버용 패키지 목록 |
| `requirements-scan.txt` | 스캔용 패키지 목록 |
| `.streamlit/config.toml` | 화면 테마 |

## 설정 방법

**1. 파일 올리기**
저장소에 모든 파일을 올립니다. `.github` 폴더는 맥에서 숨김 폴더라 안 보일 수 있습니다. 그럴 때는 저장소에서 `Add file` → `Create new file`을 누르고, 파일 이름 칸에 `.github/workflows/scan.yml`을 입력한 뒤 `scan.yml` 내용을 붙여 넣으면 됩니다.

**2. SEC 연락처 등록 (필수)**
저장소의 `Settings` → `Secrets and variables` → `Actions` → `New repository secret`을 누르고 아래처럼 입력합니다. 이메일은 실제 주소로 바꾸고, **한글은 넣지 마세요.**

- Name: `SEC_USER_AGENT`
- Secret: `INTERS Value Tracker your.email@gmail.com`

Streamlit 앱 설정의 Secrets에는 더 이상 넣지 않아도 됩니다.

**3. 첫 스캔 실행**
저장소의 `Actions` 탭 → 왼쪽 목록의 `가치투자 트래커 주간 스캔` → 오른쪽 `Run workflow` 버튼을 누릅니다. 처음이라 워크플로 사용 동의 화면이 나오면 동의해 주세요. 10~20분 뒤 초록 체크가 뜨면 완료입니다.

**4. 앱 확인**
"주간 스캔 결과 업데이트"라는 커밋이 생기고 1~2분 뒤 앱이 새 결과로 다시 시작됩니다. 브라우저에서 `Ctrl + Shift + R`(맥은 `Cmd + Shift + R`)로 새로고침하세요.

**스캔이 실패하면**
`Actions` 탭에서 빨간 X가 뜬 실행을 열어 `스캔 실행` 단계의 로그를 확인합니다. 마지막 결과 올리기 단계에서 권한 오류가 나면, 저장소 `Settings` → `Actions` → `General` → `Workflow permissions`를 `Read and write permissions`로 바꾸고 다시 실행합니다.

## 사용 방법

1. 린치 분류, 시가총액, 섹터 태그와 네 가지 토글(PEG 1 이하, 자사주 매입 중, 흑자 기업만, 경고 없는 종목만)로 종목을 좁힙니다.
2. 표에서 행을 선택하거나 `종목 바로 보기`에서 티커를 고르면 아래에 상세 화면이 열립니다. 상세 화면은 실적, 애널리스트, 가치평가·재무, 주주환원·수급, 체크리스트 탭으로 나뉩니다.
3. 사이드바의 저성장 기준(기본 5%)을 바꾸면 분류가 바로 다시 계산됩니다.
4. 앱을 업데이트한 직후 화면에 `Failed to fetch dynamically imported module` 오류가 뜨면 `Ctrl + Shift + R`로 새로고침하면 됩니다.

## 데이터 출처와 한계

- **재무 데이터: SEC XBRL 공시.** 미국 정부 공개 자료라 공유에 문제가 없습니다. 미국 회계기준으로 공시하지 않는 해외 기업(20-F 제출 기업 등)은 재무 지표가 비어 있습니다. 회사마다 공시 항목 이름이 달라 일부 지표가 `-`로 나올 수 있습니다.
- **4분기 실적:** 연간 보고서에만 나오므로 연간 값에서 1~3분기 합을 빼서 계산합니다.
- **종목 목록·시가총액·주가·섹터: Nasdaq 스크리너.** 섹터는 GICS 11개 섹터로 매핑한 값이라 공식 분류와 일부 다를 수 있습니다. Nasdaq 목록이 막히면 SEC 목록과 Yahoo 주가로 대체 스캔하며, 이 경우 섹터 정보가 비어 있습니다.
- **주가 기준일:** 주가와 시가총액은 스캔한 날 기준이라 PER, PEG, FCF 수익률은 최대 일주일 전 주가로 계산된 값입니다.
- **애널리스트·내부자 데이터: Yahoo Finance.** 종목을 열 때만 조회합니다. 개인 용도 전제의 데이터이므로 외부 공개나 게시는 피해 주세요.
- **잭스 랭크:** 약관상 재배포가 금지되어 있어 `잭스에서 보기` 링크로만 제공합니다.
- **무료 데이터로 확인할 수 없는 항목:** 매출 서프라이즈, 가이던스 하향 후 서프라이즈 여부, 특정 고객 의존도, 시장점유율. 체크리스트에 `직접 확인` 항목으로 표시됩니다.

## 내 컴퓨터에서 실행하기 (선택)

```
pip install -r requirements.txt
set SEC_USER_AGENT=INTERS Value Tracker your.email@gmail.com   (맥: export SEC_USER_AGENT="...")
python run_scan.py
streamlit run app.py
```
